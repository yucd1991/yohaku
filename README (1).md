# Yohaku（余白）

週に一度、ビジネスの日常から半歩離れて、思想と問いのために立ち止まる場所。

一人の思想家・一つの作品を深く味わい、そこから自分の仕事や日常に引き寄せた「問い」を持ち帰る、静かな週次の記録。

## 構成
- `index.html` — トップページ（号一覧）
- `reports/` — 各号の本体（HTML）
- `reports/index.json` — 号一覧データ
- `reports/report.css` — 共通スタイル
